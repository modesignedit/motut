# 💎 MODIAMOND16 — HIIT Visualizer

**Control the burn. Pressure makes diamonds.**

A single-file, zero-dependency HIIT workout visualizer with an animated SVG exercise figure, programmable timer, and session mode. Works offline from `file://`.

## Features

- **6 Programs** — MODIAMOND16 (original), Quick Burn, Tabata Blast, Core Crusher, Lower Shred, Plyo Power
- **31 Exercises** — Each with SVG stick-figure animation, beginner-friendly instructions, intensity & impact ratings, and form tips
- **Animated Figure** — Geometric humanoid drawn in SVG with real-time pose interpolation across 533+ frame values
- **Timer** — Work/rest intervals with circular progress ring, audio beeps, haptic vibration
- **Session Mode** — Run through a full program with auto-advance, rest countdown, and completion confetti
- **Search & Filter** — Real-time card filtering by name or category (Lower, Upper, Core, Full, Plyo)
- **Stats & History** — Persistent workout log with streak tracking, move count, and favorite program
- **Theme Toggle** — Dark/Light mode with glassmorphism, neon glow, and gradient text
- **Mobile-First** — Responsive layout with drag-minimize viewer, compact controls, and touch gestures
- **Keyboard Shortcuts** — Space (play/pause), ← → (prev/next), R (reset), ? (help)
- **Zero Dependencies** — Pure HTML/CSS/JS, everything inline, works offline

## Quick Start

Open `hiit-modiamond16.html` in any modern browser — that's it.
